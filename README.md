# Test comparatif : deux films 100% code

Deux courts métrages d'animation réalisés entièrement en code (Three.js), sans modèle vidéo génératif.

- **video_A.mp4** : 75 secondes
- **video_B.mp4** : 89 secondes

Protocole : regarder les deux dans un ordre quelconque, puis donner un avis (rendu, animation, direction artistique, son, histoire). Aucune autre information ne doit être lue avant d'avoir vu les deux films.

Les fichiers sont en pièces jointes de la release v1 (taille > 100 Mo, donc hors git).
